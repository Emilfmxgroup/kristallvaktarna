# Kaninväktarna

Ett tower defense-spel för mobil och dator. Kaniner vaktar skogen mot rovdjur som skickar ballongminions för att stjäla morötterna. Du väljer en hjälte före varje bana (Linnéa, Torsten eller Maja), flyttar hjälten mellan vågorna och använder hjältens förmågor Q och R.

Hela spelet är en enda HTML-fil (`index.html`) utan beroenden. Öppna den i en webbläsare, eller kör en lokal server:

```bash
python -m http.server 8765
```

Svårighetsgraden ställs in i `BAL` högst upp i skriptet.
